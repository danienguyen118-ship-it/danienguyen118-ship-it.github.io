Privacy Policy

Wasted Wiser Office · Last updated: November 20, 2026

Wasted Wiser Office is a private tool used only by its owner to manage the owner's own YouTube channels.

It uses the YouTube Data API and YouTube Analytics API to upload videos, set thumbnails, add videos to playlists, read channel statistics and reply to comments on the owner's channels.

We do not collect, sell or share any personal data of other users. Access tokens are stored only on the owner's computer and are never sent to third parties. The owner can revoke access at any time at https://myaccount.google.com/permissions.

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
